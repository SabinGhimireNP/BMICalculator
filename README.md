# BMICalculator
BMI Calcultor is a one of the medical calculation( I Think) which is used to measure the obesity of a person based on the person's weight and height.
### BMI stands - Body Mass Index.
## Important Notes

- BMI is an indicator and does not directly assess body fat or health.
- For athletes, elderly, or children, BMI may not be an accurate assessment tool.
- Always consult a healthcare provider for a thorough health evaluation.

## Formula

The BMI is calculated using the following formula:

```
BMI = weight (kg) / (height (m))^2
```

## Example
Suppose your weight is 70 kg and height is 1.75 m:

```
BMI = 70 / (1.75)^2 = 22.86
```

## Categories
 ```
| BMI Range          | Category         |
|--------------------|-----------------|
| Less than 18.5     | Underweight     |
| 18.5 – 24.9        | Normal Weight   |
| 25.0 – 29.9        | Overweight      |
| 30.0 and above     | Obese           |
```
