# BMICalculator
BMI Calcultor is a one of the medical calculation( I Think) which is used to measure the obesity of a person based on the person's weight and height.
### BMI stands - Body Mass Index.

## Formula

The BMI is calculated using the following formula:

```
BMI = weight (kg) / (height (m))^2
```

## Example
Suppose your weight is 70 kg and height is 1.75 m:

```
BMI = 70 / (1.75)^2 = 22.86
```
